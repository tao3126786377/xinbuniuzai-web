# 牛仔决斗微信小游戏

当前已接入“快速 · 人机对战”和“完整 · 人机对战”。

快速人机模式复用网页端的规则、均衡表和自适应电脑策略。完整人机模式通过现有 Render 服务计算，支持选弹、五轮筹码、回合记录、结算、跨局记忆和再来一局。两个玩家对决模式仍在迁移中。

第一次打开会单独询问是否启用“个性化强化策略”。允许后，两种人机模式的策略记忆保存在独立的 CloudBase 集合中，用于跨局适应；拒绝后仍可游玩，但每次从基础记忆开始。第一次进入人机模式还会另行询问是否贡献训练数据，拒绝不会影响任何策略功能。两个授权使用不同集合、不同 HMAC 密钥和独立删除入口，策略记忆不会进入训练数据导出库；数据库均不保存 OpenID 原值、昵称或头像。

开发者工具联调时可临时勾选“不校验合法域名”。正式发布前，必须在微信后台配置 `https://xinbuniuzai-web.onrender.com` 为 request 合法域名，并按 `CLOUDBASE_SETUP.md` 部署两个云函数、创建两个数据库集合和配置两把不同的云端 HMAC 密钥。

在微信开发者工具中点击“编译”即可预览当前页面。
