# 第四阶段：决策相关的历史信息

离线研究，沿用冻结的行为预测器。研究范围是定位值得小网络学习的时序规律，不修改快速模式、人机网页或联机协议，不部署。

## 复现

从 `web/` 目录运行；Python 需要已有 NumPy、SciPy、Numba 依赖，包支持 `research/.deps/`：

```powershell
$env:OPENBLAS_NUM_THREADS='1'
python -m research.match_ai.phase4 run
python -m research.match_ai.phase4 endgame
python -m unittest discover -s research/match_ai/tests -v
python -m research.match_ai.phase4 report
```

默认完整均衡表 `research/artifacts/full`；冻结网络及校准参数 `research/match_ai/phase3/results`。`run` 默认 11 类各 128 位玩家、四个进程；`--profiles`、`--workers` 可缩小试跑，避免覆盖正式结果时同时指定 `--output research/artifacts/phase4_pilot`。`endgame` 是事后补充审计，需样本中存在最后七手以内的 mimic 局面，小规模试跑不保证有。

正式实验共 1,408 局均衡轨迹、每局抽一个已观察过玩家的状态；另有每类 118 条合法受控历史。新种子前缀 `[20260925,4]`；同一玩家的参数、动作采样、状态抽样使用不同流。受控实验用玩家编号 1,000,000，与自然样本分开。行为族沿用既有 11 类，不能称为全新行为族测试。没有新超参数选择或网络训练。

自然轨迹日志保留决策前状态、公开动作、观测序号、结算、终局分数及抽样位置。策略输入只有公开状态、过去历史和过去证据；知道生成器类型的参考模型只用于评估。所有输出均为合成数据。

## 指标和边界

- `evaluate`：共同 1/2/3 步真实对手参考；两步网络、三步网络、三步自适应均用相同安全约束。保存参考分数、当前动作机会损失、预测 KL、概率分布和节点安全检查。
- `matched_histories`：真实初始状态出发，穷举四次双方同步动作，子弹恢复初始值，末尾双方防御。按九个选弹组合分组；同组**整个 State 相同**，绝不拼接非法历史。
- `history_value`：每条历史独立选根动作，与所有历史共用根分布的最优平均值相减。后续仍知道真实历史；不是完整“无记忆玩家”对照。组内等权，不代表自然发生概率。
- `terminal_oracle`：最后一轮已知 mimic 对手的精确安全终局 DP。该对手只用当前轮最近两手，允许压缩该参考的历史；网络评价始终保留完整八事件输入。
- `terminal_policy`：让控制器在每个后续状态重新决策，用真实对手概率枚举终局胜/平/负。评估末端不使用均衡价值，不把参考策略偷偷替换为候选的后续行为。

主实验的叶节点仍是均衡延续，三步是有限前瞻，不是求解整个信念树。网络在未来分支上的预测也可能出错。根动作机会损失不能当作实际连续执行的整局损失；补充审计专门验证这个区别。

`protocol.json` 在采集结果前写入；权重全程冻结。后追加的 `endgame` 挑选三步网络机会损失最大的合格 mimic 样本，报告明确标为事后分析，不能用于总体胜率推断或充当下次独立测试。

`results/` 保存报告、紧凑汇总、协议、终局审计及 SHA-256；`research/artifacts/phase4/` 保存逐状态概率和可重放轨迹。自然轨迹每个样本对应独立玩家；bootstrap 是探索性局部指标区间。受控历史彼此相关，不把它们当独立玩家做显著性检验。

安全继续为每步 `min(p @ Qeq) >= Veq - 0.0199/505 - 1e-11`，配合完整基线误差后总界小于 0.02。温度保持 0；分布仍可以是混合策略。没有通过调整安全预算人为扩大预测改进的收益。
